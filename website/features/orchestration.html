Orchestrate agents

Ten projects. One window.

TUICommander knows what each agent is doing. You follow one orchestrator, and the rest come to you when they need you.

The sidebar tells you everything.

The rich layout adds facts to every row without losing density.

  • Branches show the pull request state and title, ahead and behind, diff stats, dirty files, and merged or stale status.
  • Agents show Working, Idle, Needs input or Error and what they are doing now; their subagents and child sessions nest below them.
  • Repositories show open PRs, worktrees and the last remote poll. Groups, colours and parking keep ten projects in order.

Any agent. One gesture.

Open the agent menu and pick Claude Code, Codex, Gemini, Grok, ego or any other supported agent. The launch uses the run configuration you saved for it, with its own flags and environment, in the branch or worktree you are on.

Read it like a chat.

Terminals that run Claude Code, Codex, Grok or ego have a CLI | Chat switch. Chat shows the session as a conversation: your prompts, the agent's answers, and each tool call folded into one card. The terminal keeps running underneath, and you reply or queue the next task from the composer.

Read the Terminals guide →

It knows which agent.

Questions, approvals and rate limits are detected as they appear, and the tab, the sidebar and the notifications tell you which agent is waiting. The Activity Dashboard (Cmd+Shift+A) lists every session's state in one view.

Read the Activity Dashboard guide →

Agents spawn agents. And talk to each other.

Through TUICommander's MCP tools an orchestrator creates worktrees, starts child agents with a prompt, and sends them messages. Children report back with done or blocked.

  • Progress keeps an append-only journal per project, with a toolbar bell for what arrived since your last look.
  • Flow draws the same journal as a sequence diagram: one column per agent, arrows for delegations, messages and results. See who said what.

AI Chat, with ego experimental

AI Chat is a conversation with ego, which TUICommander launches and speaks to over ACP. TUICommander is the environment, with its terminals, repositories and MCP server; ego is the intelligence. Turn on Experimental Features and set the ego executable in Settings → General.
