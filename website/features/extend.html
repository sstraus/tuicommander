TUICommander is an open platform. Your agents, your tools and your scripts reach the same backend the app uses.

One endpoint, every MCP server.

The MCP Proxy Hub connects your upstream MCP servers, over HTTP or stdio, to TUICommander's own endpoint. Every agent connects once and gets every upstream tool, prefixed with the server's name.

  • Add or remove servers without restarting anything.
  • Health checks and live status per upstream.
  • Credentials from the OS keyring, secret header rows, and tool filters per server.
Read the MCP Proxy Hub guide →

Prompts that know the context.

Smart Prompts fill in the branch, the diff, the changed files and the PR before they reach your agent. Run them in the agent terminal, headless as a one-shot, or as a plain shell script. The library (Cmd+Shift+K) keeps the built-in prompts and your own.

Read the Smart Prompts guide →

Your own tools, in JavaScript.

Plugins are plain JavaScript modules with hot reload. Install them from the community registry, a ZIP file or a deep link.

Plugins and the TUIC SDK

Watch terminal output, add Activity Center items, panels and Markdown content, through capability tiers you grant.

The tuic CLI

Open files and repositories, use TUICommander as $EDITOR, manage sessions and spawn agents from any shell.

HTTP API

Drive sessions, repositories and agents over HTTP and WebSocket, with the same API the browser and the phone use.

Private secret forms

An agent requests named fields with the secret MCP tool. You type into a separate window; the agent receives stored or declined, never the value.

MDKB

Install MDKB from Settings for go-to-definition, references, a symbol outline and long-term memory for agents.
