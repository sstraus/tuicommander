Workspace

Your files, right here.

Everything around the terminal, so reading what an agent wrote never means opening another app.

Markdown, reviewed in place.

Plans and notes open in the Markdown panel with highlighted code and live task checkboxes. Comment on any passage: the comment is stored inside the .md file as an invisible marker, so the agent reads your review the next time it opens the file. Links to files and lines open inside TUICommander.

And the rest of the workspace

File browser and editor

Tree or flat view with Git status, filename search with * and ** globs, content search, and a CodeMirror editor that detects changes on disk.

Design Mode

Collect page elements and comments in a browser sidebar, then send the feedback to an agent.

Split panes and zoom

Split the terminal side by side or stacked, maximize a pane, and zoom each terminal on its own.

Suspend a tab

End a tab's process to free its memory and CPU, keep the tab, and resume the agent's conversation later.

Keyboard first

Cmd+U jumps to the next agent that waits for you, across repositories. Every shortcut can be rebound.

Command palette

Every action by name, from one fuzzy search.
