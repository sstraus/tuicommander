Install from the shell

The shell installer and Homebrew install the stable release. An installed beta or nightly stays on its channel when you run the shell installer again.

Channels

2.0 is in beta. The buttons above give the newest release. To install the beta from the shell on macOS or Linux, pass the channel name:

curl -fsSL https://tuicommander.com/install.sh | sh -s beta

The nightly build follows main and installs with sh -s nightly. In the app, Settings → General → Update Channel selects Stable, Beta or Nightly for updates.

System requirements

  • macOS 12 Monterey or later. Mermaid diagrams need the system WebKit of Safari 17.4 or later.
  • Windows 64-bit with the WebView2 runtime.
  • Linux x86_64 with WebKitGTK.

The tuic-remote daemon (beta) has its own binaries for Linux, macOS and Windows on each release page.
