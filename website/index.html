Questions

Is it free?
Yes. TUICommander is open source under the Apache 2.0 licence, with no subscription and no feature gates.
Which agents does it support?
Eleven are detected natively: Claude Code, Gemini CLI, OpenCode, Codex CLI, Amp, Cursor Agent, Goose, Grok, Droid, pi and ego. See Agent Support.
Which systems does it run on?
macOS 12 or later, Windows and Linux. The tuic-remote daemon (beta) runs headless on Linux, macOS and Windows machines that have no desktop.
Can I use it without AI agents?
Yes. It is a full terminal workspace on its own: split panes, worktrees, an editor, diffs, Git and pull requests, with sessions that survive restarts.
Does my data leave my machine?
The app sends no telemetry. It makes network calls only for features you use: GitHub, GitLab and Jira APIs, the plugin registry, the end-to-end encrypted cloud relay, and spoken replies, whose default voices are Microsoft Edge online voices. Choose Pocket TTS to keep speech on your machine; dictation always runs locally with Whisper.
Can I follow my agents from my phone?
Yes. Open the mobile companion over your network, Tailscale or the encrypted relay, add it to your home screen, and answer questions or read sessions from there. See Remote Access.
