Boss revised chunk 1 on 2026-11-02 to ego with `openai-codex/gpt-6-luna` and a separate Team-account base-model reviewer, with explicit sandbox/mode variants. Earlier runs retain their original routing as historical evidence. Authenticated real model generation is required. No mock agents, stores, GitHub services, Docker health, or loopback model stubs count as e2e proof. Non-agent commands are real processes.
- Bounds below are proposed outer harness deadlines, armed after preflight; model and effect deadlines must be smaller and separately named. A deadline fails with the pending effect and logs, never treats absence as success. Each parameter row is a separately reported case. Serialize heavy scenarios on rb where headless execution is supported; native UI checks run serially on Mac.
- Per case capture candidate Git commit/tree, daemon binary digest, definition/policy digests, model/harness/tool versions, owning daemon/run/attempt IDs, actual command, timestamps, exit, files/commit trees, raw receipt/event/provider IDs and owned-process stop proof. Reread the real store through its API after restart. Secret values are excluded.
- Pass requires observable effects and their provenance. Run-state assertions accompany actual files, commits, process absence or provider objects; labels alone never suffice. Notification proof requires receiver read-back. Unknown usage stays unknown.
- Proposed single entrypoint for phase 2: `scripts/workflow-e2e.sh --candidate <commit> --manifest <sandbox-config> --evidence <directory>`. The entrypoint exists; its current selectors implement bounded subcases, not complete family coverage. Preflight fails closed on missing binaries, models, sandbox ownership, policies or provider grants. Boss approved a three-hour cap on 2026-11-02, with serial chunks and the most relevant first. Chunk 1 includes the local families plus E13, E14, E28 and E32. External scenarios remain blocked until their exact grants and setup exist; unmet required cases prevent a full gate PASS.
- GitHub write cases require an explicitly named disposable repository and action grant. Empty unattended publication allowlist stays empty. This task authorizes no production publication or cutover. Fabbrica uses separate panel/node/worker state and non-production GitHub resources.
